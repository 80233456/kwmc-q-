# 怎么把「音乐盒 Studio」发给别人用（含本次报错的原因）

## 你遇到的报错

```
Failed to load Python DLL
'C:\Users\zcw\Downloads\_internal\python311.dll'. LoadLibrary: 找不到指定的模块。
```

**原因：只发了 exe，没有发它旁边的 `_internal` 文件夹。**

打包有两种形态，规则完全不同：

| 形态 | 产物 | 发给别人时 |
| --- | --- | --- |
| **单目录版**（原来的） | `音乐盒Studio\音乐盒Studio.exe` **+ `_internal\`（200+ 个文件、约 139 MB）** | ❌ **不能只发 exe**！必须整个文件夹打包成 zip 发（解压后双击里面的 exe） |
| **单文件版**（本次新增） | `音乐盒Studio-单文件版.exe`（**55.4 MB，一个文件**） | ✅ 直接发这一个 exe 就行 |

> 那个 `_internal` 里装着 Python 运行时（`python311.dll`）、Qt6 界面库、FFmpeg 解码器等。
> 单目录版把 exe 和它们分开放，好处是启动快；**但 exe 单独一个就是废的**（你这台就撞上了）。
> 单文件版把它们全部塞进 exe，运行时自动解压到 `%TEMP%`。

---

## 推荐：直接发单文件版（已实测）

产物：`dist\音乐盒Studio-单文件版.exe`（55.4 MB）

实测（拷到独立目录、周围没有任何 `_internal`）：

```
OK: window appeared in 3.2s  title='音乐盒 Studio'  mem=125MB
extracted dir: C:\Users\...\Temp\_MEI114282   136.9 MB / 204 files
```

* 对方电脑**不需要装 Python**，也不需要装 VC++ 运行库（已随包打进）；
* 首次启动约 3 秒（自解压），之后同样 3 秒左右；
* 若被杀软拦截：加白名单即可（PyInstaller 打包的程序常被误报）。

---

## 备选：发整个文件夹（启动最快、体积最小）

1. 把 `dist\音乐盒Studio\` **整个文件夹**压缩成 zip；
2. 对方解压后双击里面的 `音乐盒Studio.exe`；
3. ⚠️ 千万别只把 exe 拖出来。

```powershell
Compress-Archive -Path "dist\音乐盒Studio\*" -DestinationPath "dist\音乐盒Studio-单目录版.zip" -Force
```

---

## 重新打包（改完源码后）

| 脚本 | 产物 | 耗时 |
| --- | --- | --- |
| `打包-单文件.bat` | `dist\音乐盒Studio-单文件版.exe`（单文件，推荐发放） | 1~2 分钟 |
| `打包-单目录.bat` | `dist\音乐盒Studio\`（文件夹版） | 约 1 分钟 |

---

## 数据存哪里（两种版本都是持久化的）

| 内容 | 位置 |
| --- | --- |
| 下载的歌曲 | `%USERPROFILE%\Music\音乐盒Studio\` |
| 设置（音质/音量/目录） | `%LOCALAPPDATA%\MusicBoxStudio\studio_settings.json` |
| 歌词缓存 | `%LOCALAPPDATA%\MusicBoxStudio\lyrics\` |

> 单文件版每次运行都会解压到新的 `%TEMP%\_MEIxxxx`，所以配置/缓存**不能**放在程序目录
> —— 这一点已经专门处理过，否则每次退出就丢设置。

---

## 目标电脑的要求

| 系统 | 是否可运行 |
| --- | --- |
| Windows 10 / 11（64 位） | ✅ 直接运行（已实测） |
| Windows 8.1（64 位） | ✅ 一般可以（若报缺 `api-ms-win-crt-*.dll`，装“通用 C 运行时更新 KB2999226”） |
| Windows 7 | ❌ Python 3.11 不支持 Win7（需另用 Python 3.8 重新打包） |
| 32 位 Windows | ❌ 本包是 64 位（需另打 32 位包） |

判断对方系统：`Win+R` → `winver` → 看版本号。

---

## 一句话结论

> **单目录版 = exe + `_internal` 必须一起发；要"就发一个文件"，用单文件版（55.4 MB）。**
