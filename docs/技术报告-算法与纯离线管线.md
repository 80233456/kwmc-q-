## 三、算法真相（我们此前卡住的根因）

```
密钥：b"ylzsxkwm"          ← 我们早就猜到了
但：这是【自定义 DES 变体】—— 自定义 S 盒 MATRIXNSBOX + 自定义 IP/FP/PC/P/E 置换表
所以：用标准 DES 库去试永远失败（实测 205,595 个密钥候选全灭，原因在此）
实现：base64( 自定义DES(明文, mode=0) )        ← 加密
      自定义DES(密文, mode=1) → 明文           ← 解密（可用于分析抓包）
```

**我们的验证（决定性）**：
```
抓包里的真实 q 长度        : 672 字符
用我们解出的明文重加密      : 672 字符
逐字节完全一致             : True      ← 实现 100% 正确
回放到 mobi.s?f=kuwo&q=    : HTTP 200  ← 服务端认可
```
并且**直接用算法解密了 App 的真实请求**，看到了完整明文（含 loginUid/loginSid/q36/oaid 等）：

```
user=…&android_id=…&prod=kwplayer_ar_12.2.2.4&corp=kuwo&…&q36=…&approval=false
&loginUid=<loginUid>&loginSid=<loginSid>&appuid=<appuid>&allpay=1&notrace=0
&oaid=7F91…&vipMode=0&type=lyric&songname=怪咖&artist=薛之谦&duration=250000
&req=2&lrcx=1&rid=45718040&encode=utf8
```

## 四、可用的 PC 纯离线管线

`kuwo_pc_download.py`（配合 `kuwo_q.py`）：

```
1) search.kuwo.cn/r.s        关键词 → rid
2) kuwo_q.encrypt_kuwo_query 本地生成 q（无需手机）
3) mobi.kuwo.cn/mobi.s?f=kuwo&q=<q>   + UA: okhttp/3.10.0
   → 明文参数：user=0&corp=kuwo&source=kwplayer_ar_5.1.0.0_B_jiakong_vh.apk
              &p2p=1&type=convert_url2&sig=0&format=flac&rid=<rid>
4) 响应文本里取 url=  → 直接下载 FLAC
5) 顺带拉歌词（m.kuwo.cn/newh5/singles/songinfoandlrc）
```

用法：

```powershell
python kuwo_pc_download.py "晴天 周杰伦"        # 搜索并下载第一首
python kuwo_pc_download.py "周杰伦" --all       # 下前 5 首
python kuwo_pc_download.py --rid 228908         # 指定 rid
```

**要点**（踩过的坑）：
* q **必须原样发送，不能做 URL 编码**（`+` `/` 保持原样，与 App 一致），否则 404；
* UA 用 `okhttp/3.10.0`；
* 时间戳/随机量：**无**（同一明文 → 同一 q，已验证），所以可离线生成、可缓存。

## 五、能力边界（如实说明）

| 情况 | 结果 |
| --- | --- |
| 普通曲目 | ✅ 完整无损 FLAC（抽样 7/7） |
| 会员独占曲（如《七里香》rid=1307392909） | ⛔ 服务端只给片段/拒绝（权限在服务端，客户端声明的 `vipMode=1`/`isVip=1` 等一律被忽略） |
| 社区做法（musicdl 等） | 会员曲靠**第三方解析 API**（gdstudio / haitangw / nxinxz / xcloudv / lxmusicapi，实测大多已失效或不支持酷我）或**跨平台兜底**（如 gdstudio 直接返回网易云 320k） |

**仍未知的一点**：破解版 App 是怎么拿到会员曲无损的（很可能用了内嵌的会员账号）。
要确认只需一步：**手机连上后抓一次"播放请求"（不是歌词请求）并解密**即可看清它的账号与参数——
我们现在有解密器，这一步几乎是确定性的。目前手机未连接，故暂停。
