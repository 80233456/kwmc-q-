# 音乐盒 Studio · 使用说明

酷我音源的现代化桌面播放器：**在线搜索 · 直接试听 · 无损下载 · 本地曲库 · 歌词**
界面基于 **PySide6 / Qt 6.11**（业界主流现代桌面框架，非 tkinter 那类老旧方案）。

---

## 启动

| 方式 | 说明 |
| --- | --- |
| **桌面快捷方式** | 已生成：双击桌面「音乐盒 Studio」（`创建桌面快捷方式.bat` 可重建） |
| **双击 `启动音乐盒.bat`** | 优先启动打包版，没有则用 Python 运行 |
| 直接跑 exe | `dist\音乐盒Studio\音乐盒Studio.exe`（**独立程序，不需要装 Python**，实测 138.8 MB / 205 文件，启动后内存约 127 MB） |
| 开发态 | `python kuwo_app.py` |

> 打包版首次启动会自动把下载目录设为 **`%USERPROFILE%\Music\音乐盒Studio`**（符合常规软件习惯）；
> 源码运行则用项目内 `work/pc_downloads`。也可在「设置」页随时改。

## 功能

### 1. 搜索
* 支持 歌曲 / 歌手 / 专辑 / 混合关键词（例：`富士山下 陈奕迅`）
* 结果表：**专辑封面缩略图**、歌名、歌手、专辑、时长、**可用音质与体积**（`VIP · FLAC 26.6M`）、
  行内 **试听 / 下载** 图标按钮
* 搜索中行会加粗高亮（正在播放的那首一眼可见）
* 容错解析：接口返回的脏数据（值里带未转义引号）不再导致"搜不到"

### 2. 试听（不需要下载）
* **双击任意一行即可播放**：后台解析线上地址，直接流式播放（QtMultimedia/FFmpeg）
* 播放条：⏮ ▶/⏸ ⏹ ⏭、播放模式（顺序/随机/单曲）、进度拖动、时间、音量（可静音）
* 播放时显示**律动指示**（三根跳动竖条），暂停即隐藏
* 空格 播放/暂停，← → 快退/快进 5 秒，Ctrl+F 聚焦搜索

### 3. 下载
* 行内 ⬇ 按钮或右键 → **下载（当前音质）**
* 「下载队列」页：**真实进度百分比 + 进度条**，完成后自动清理进度控件，显示 `✓ 完成 26.6 MB`
* 完成后**按内嵌标签自动规范命名**，可选同时保存歌词（`.lrc`）
* 音质：`无损 FLAC` / `320k MP3` / `128k MP3`（拿不到时自动降级尝试）

### 4. 本地曲库
* 自动扫描下载目录；FLAC 用强调色音符、MP3 用灰色音符区分
* 双击播放，右键 播放 / 资源管理器定位 / 删除（连 `.lrc`）

### 5. 歌词页（整页大字版）
* 播放时自动拉取，四级降级：**酷我 http → 酷我 https → App 加密通道 → 网易云兜底**，并落盘缓存
* **平滑滚动**（60fps 缓动，不跳变）
* **卡拉OK 渐变填充**：当前行按播放进度紫→青渐变点亮
* **切行弹入动画** + 药丸底色；远处行按距离淡出，上下渐隐
* **点击任意一行 → 跳到该句**并继续播放
* 播放条上的 💬 按钮一键直达歌词页

### 6. 设置
* 下载目录可改；启动音量；**缓存统计**（歌词/封面/本地数量）与一键清空；关于信息
* 设置自动保存到 `work/studio_settings.json`

## 打包成独立软件

```powershell
python -m PyInstaller --noconfirm --clean --windowed ^
  --name "音乐盒Studio" --icon appicon.ico --add-data "appicon.ico;." ^
  --exclude-module PySide6.QtWebEngineCore --exclude-module PySide6.QtWebEngineWidgets ^
  --exclude-module PySide6.Qt3DCore --exclude-module PySide6.QtCharts ^
  --exclude-module PySide6.QtQuick --exclude-module PySide6.QtQml ^
  --exclude-module tkinter --exclude-module matplotlib --exclude-module numpy ^
  kuwo_app.py
```

产物：`dist\音乐盒Studio\音乐盒Studio.exe`（整个文件夹可拷贝到任意电脑运行）。
想做成**单文件**：把 `--windowed` 换成 `--windowed --onefile`（体积更小但启动稍慢）。

## 技术结构

```
kuwo_app.py            ★ PySide6 界面（搜索/曲库/歌词/队列/设置 + 播放条）
ui_kit.py              ★ 界面组件库：矢量图标、图标按钮、动画歌词、律动条、空状态、Toast、Spinner
kuwo_pc_download.py    引擎：搜索 / 解析地址 / 下载 / 歌词（四级降级+缓存）/ 标签读取
kuwo_q.py              q 参数加解密（自定义 DES，密钥 ylzsxkwm）
appicon.ico            应用图标（脚本生成）
启动音乐盒.bat / 创建桌面快捷方式.bat
```

* **图标系统**：全部 QPainter 矢量绘制 → 不依赖字体，任意尺寸/颜色/状态清晰一致，高清屏按 DPR 渲染；
* **动效**：统一用 60fps 定时器 + 缓动插值（歌词滚动/切行弹入、导航指示条、Toast 淡入、律动条）；
* **线程模型**：`Engine` 把网络操作放进 `QThread`（`Worker`），完成后通过信号回主线程，UI 不卡顿；
* **播放**：`QMediaPlayer + QAudioOutput`（FFmpeg 后端，MP3/FLAC/流式 HTTP 全支持）；
* **封面**：搜索结果的 `web_albumpic_short` → `https://img1.kuwo.cn/star/albumcover/500/...`，内存缓存。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 搜不到某首歌 | 换个写法（歌手+歌名），或先只搜歌名；接口偶尔抽风，重试即可 |
| 某首放不了 | 该曲受限（服务端只给片段）；换个版本（Live/翻唱）通常能放 |
| 下载卡住 | 看「下载队列」页状态；网络波动时重新下载即可 |
| 没有声音 | 检查系统音量 / 播放条音量条；确认输出设备 |
