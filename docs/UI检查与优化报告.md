## 1. 发现的问题与修复

### 1.1 图标：根因是"用 emoji/字符当图标"

原实现用 `🔍 💾 ⬇ ⚙ ⏮ ▶ ⏸ ⏭ 🔊 🎵 ♪` 等字符。这类字形**依赖系统字体**，会出现缺字方块、宽度不一致、
选中态不变色、大小无法统一、高清屏发虚。

**修复：自建矢量图标系统**（`ui_kit.py`，QPainter 绘制，零字体依赖）

* 27 个图标：search / library / download / settings / play / pause / stop / prev / next /
  volume / mute / lyric / folder / refresh / trash / queue / note / shuffle / repeat / repeat1 /
  check / close / external / heart / vip / spinner / warning
* 任意尺寸、任意颜色（含激活色）、按设备像素比渲染 → 高清屏锐利
* 审查中发现并修掉 4 个语义/观感问题：

| 图标 | 问题（看图发现） | 修复 |
| --- | --- | --- |
| `settings` | 圆形+八根辐条，看着像**太阳/星号**，不像设置 | 改为**推杆 sliders**（三线三钮），语义无歧义 |
| `lyric` | 三条横线，与"下载队列"图标**几乎一样** | 改为**对白气泡+文字行**，一眼可辨 |
| `library` | 三竖线带钩，含义模糊、重心偏左上 | 改为**卡片+播放三角**（曲库卡片） |
| `spinner` | 是一段静止弧线，**没有旋转** | 新增 `Spinner` 控件：60fps 旋转 + 底环 |

### 1.2 歌词页：最严重的问题（显示错 + 无动效）

原实现是 `QFrame + QLabel`，把整段歌词**一次性塞进一个标签**：没有滚动、没有逐行高亮、
没有进度反馈，行数多时完全不可用。

**修复：自绘动画歌词组件 `LyricsView`**（`ui_kit.py`）

| 能力 | 实现 |
| --- | --- |
| **平滑滚动** | 60fps 定时器 + 缓动插值（`offset += (target-offset)*0.18`），切行不跳变；实测 120 帧收敛偏差 < 0.05 |
| **卡拉OK 渐变填充** | 当前行画两遍：暗色底 + 按播放进度裁剪的高亮（紫→青渐变），"唱到哪亮到哪" |
| **切行弹入** | 新行有 0.6 秒的弹入进度，药丸底与高亮同步渐显 |
| **层次感** | 按与当前行的距离衰减透明度，远处行淡出；上下加渐隐遮罩 |
| **点击跳转** | 点任意一行 → `seekRequested(ms)` → 播放器跳转并续播 |
| **独立歌词页** | 侧栏新增「歌词」入口（整页大字版），播放条上的「词」按钮一键直达 |

审查中修掉的具体缺陷：

1. **背景是白的**（自绘控件没铺底色，露出上位白色）→ 组件自己 `fillRect` 主题底色；
2. **激活行是空行时只剩一根孤零零的指示条**（歌词前奏常有空行）→ 解析时过滤空白行 + 去掉浮动指示条，改用**药丸底 + 高亮文字**表达焦点；
3. 行距/字号偏小 → 行高 42px、激活行 14pt 粗体、普通行 11pt。

### 1.3 播放条与队列

| 问题 | 修复 |
| --- | --- |
| 播放条按钮全是字符符号，播放/暂停切换时**宽度跳动** | 全部换成定尺寸 `IconButton`（40/44/36px），图标切换不跳版 |
| 律动指示条**未播放时也显示** | 只在播放时显示（隐藏不占位） |
| **下载没有真实进度**（原为假进度条） | 改为分块下载 + `progress(rid, pct)` 信号 → 队列页**真实百分比 + 进度条** |
| 下载完成后**进度条控件仍盖住状态文字** | 完成后 `removeCellWidget` 移除控件（不是仅隐藏），状态列显示「✓ 完成 26.6 MB」 |
| 「音质」列太窄，`VIP · FLAC 26.62Mb` **换行** | 列宽 140→168，文案缩为 `FLAC 26.6M` |
| 队列页「状态」列文字被截断 | 列宽显式设置（120/110/150/190） |

### 1.4 其他

* 侧栏导航从 `QListWidget + emoji` 换成自绘 `NavItem`：**渐变药丸 + 左侧指示条 + 悬停淡入**（动画而非硬切）；
* 搜索结果新增 **VIP 徽标**（`pay=16711935` → `VIP · …`）、**播放行高亮**（加粗+强调色）；
* 空状态从"空白页"改为**图标+主标题+提示**（搜索/曲库/队列各自文案）；
* 新增 **Toast 浮出提示**（右下角，淡入淡出，替代只有状态栏干巴巴一行）；
* 设置页从 1 张卡扩到 3 张（下载目录 / 播放音量 / 缓存统计与关于，含"清空歌词缓存""清空封面缓存"）。

## 2. 顺带修掉的功能缺陷

* **歌词接口失效**：原用 `https://m.kuwo.cn/newh5/...` 被限流（`音乐查询失败/301`）。
  实测发现 **`http://` 同路径可用**（HTTPS 被限流、HTTP 正常）。
  已改为三级降级：**http H5 → https H5 → App 加密通道 → 网易云兜底**，并加**磁盘缓存**
  （`work/lyrics/<rid>.lrc`）：首取 0.1~0.5s，二次 0.014s。实测富士山下 65 行 / 七里香 38 行 / 不要说话 44 行 ✓
* **时长单位**：搜索结果 `duration` 是**秒**，接口要**毫秒** → 自动换算（<10000 视为秒）。

## 3. 举一反三：这轮总结出的界面规则

1. **图标不要用字符/emoji**：一律矢量绘制，颜色尺寸状态可控，永不受字体影响。
2. **自绘控件必须自铺背景**：否则在某些父容器/渲染路径下会露出白底。
3. **空数据要专门处理**：空歌词行、空目录、空队列、搜索无结果——都要有明确视觉表达。
4. **一个数据源不可靠就做降级链 + 缓存**：歌词走四级降级，便宜且稳。
5. **进度必须真实**：假进度条骗不了用户；用分块读取上报真实百分比。
6. **控件不是隐藏而是移除**：表格单元格里的控件（进度条）要用 `removeCellWidget`，否则会盖住文本。
7. **列宽要按内容实测**：先渲染再看图，窄了就把文案缩短或把列加宽。
8. **动效要有语义**：导航选中、切行弹入、律动条、Toast 淡入——动画服务于"发生了什么"，不是装饰。
9. **改 UI 保持接口名不变**（`tbl/songs/play_row/download_song/...`）：这样原有回归脚本直接复用，
   本轮 `app_test.py` **4/4 通过**（搜索 32 条 / 试听 / 下载 / 歌词 65 行）就是靠这条。
10. **验收方式**：渲染截图 → 看图 → 改 → 再截图复核。纯读代码看不到"像太阳的设置图标"和"白色歌词背景"。
